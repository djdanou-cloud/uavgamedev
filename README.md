# Colonel Air-defense: The Danger Wave

Single-player 2D wave-defense for Android (Google Play). You command the integrated air
defense of a city against escalating raids of UAVs, cruise missiles and ballistic missiles:
fight the wave in real time, then spend the debrief income on radars, guns, SAMs, EW and
logistics before the next one. Fictional factions and equipment throughout.

- **Engine:** Godot 4.7.2, GDScript with strict static typing, Compatibility (OpenGL ES 3) renderer
- **Platform:** Android only, arm64, phones first; no network, no accounts, no analytics; local saves
- **Team:** one developer directing AI coding agents
